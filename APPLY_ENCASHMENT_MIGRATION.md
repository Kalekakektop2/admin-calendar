# Применение миграции для инкассации

## Шаги для применения миграции

### Вариант 1: Через Supabase Dashboard

1. Зайдите в ваш проект на [supabase.com](https://supabase.com)
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла `supabase/migrations/005_encashment.sql`
4. Вставьте код в SQL Editor
5. Нажмите **Run** для выполнения миграции

### Вариант 2: Через Supabase CLI (если установлен)

```bash
supabase db push
```

## Что создает миграция

- Добавляет поле `encashment` в таблицу `shifts`
- Тип поля: DECIMAL(10, 2)
- Значение по умолчанию: 0
- Поле позволяет хранить сумму инкассации для каждой смены

## Проверка после применения

После применения миграции проверьте в Supabase Dashboard:

1. В разделе **Database** > **Tables** > **shifts** должно появиться поле `encashment`
2. Убедитесь, что тип поля - `numeric` или `decimal`
3. Значение по умолчанию должно быть `0`
