# Исправление проблемы с расчетом премии

## 🐛 Проблема

Премия не рассчитывалась корректно по двум причинам:
1. **Предварительный расчет** был от `cash_balance` вместо `total_revenue`
2. **Триггер базы данных** перезаписывал клиентский расчет (15%) на свой (5%)

## 🔧 Решение

### Шаг 1: Отключить триггер автоматического расчета

В Supabase Dashboard → SQL Editor выполните код из файла `DISABLE_BONUS_TRIGGER.sql`:

```sql
DROP TRIGGER IF EXISTS trigger_auto_calculate_bonus ON shifts;
```

Это отключит автоматический расчет премии в базе данных и позволит использовать клиентский расчет (15% от выручки).

### Шаг 2: Обновить конфигурацию бонусов (опционально)

В Supabase Dashboard → SQL Editor выполните код из файла `supabase/migrations/006_update_bonus_config.sql`:

```sql
UPDATE bonus_config 
SET bonus_percentage = 15.00,
    updated_at = TIMEZONE('utc', NOW())
WHERE is_active = true;
```

Это обновит конфигурацию бонусов в базе данных до 15% (если вы решите снова включить триггер).

### Шаг 3: Удалить все старые смены

В Supabase Dashboard → SQL Editor выполните код из файла `DELETE_ALL_SHIFTS.sql`:

```sql
DELETE FROM shifts;
```

Это удалит все старые смены с неправильными премиями.

## ✅ Проверка

После выполнения этих шагов:

1. Попробуйте создать новую смену
2. Введите общую выручку (например, 10000)
3. Проверьте предварительную премию: должна быть 1500 (15% от 10000)
4. Закройте смену
5. Проверьте премию в таблице: должна быть 1500

## 📊 Логирование

Теперь в консоли браузера вы увидите:
- `Расчет премии:` - показывает расчет на клиенте
- `Премия в созданной смене:` - фактическое значение в БД
- `Премия должна была быть:` - ожидаемое значение
- Предупреждение если триггер перезаписал значение

## 🔙 Возврат триггера (если нужно)

Если нужно снова включить автоматический расчет премии в базе данных:

```sql
CREATE TRIGGER trigger_auto_calculate_bonus
    BEFORE INSERT OR UPDATE ON shifts
    FOR EACH ROW
    EXECUTE FUNCTION auto_calculate_shift_bonus();
```

Но сначала убедитесь, что конфигурация бонусов обновлена до 15%.
