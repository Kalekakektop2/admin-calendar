# Применение миграции для таблицы штрафов

## Шаги для применения миграции

### Вариант 1: Через Supabase Dashboard

1. Зайдите в ваш проект на [supabase.com](https://supabase.com)
2. Перейдите в **SQL Editor**
3. Скопируйте содержимое файла `supabase/migrations/004_fines.sql`
4. Вставьте код в SQL Editor
5. Нажмите **Run** для выполнения миграции

### Вариант 2: Через Supabase CLI (если установлен)

```bash
supabase db push
```

## Что создает миграция

- Таблицу `fines` для хранения штрафов администраторов
- Поля: id, user_id, amount, date, comment, created_at
- Row Level Security (RLS) политики для защиты данных
- Администраторы видят только свои штрафы
- Руководители могут видеть, создавать, обновлять и удалять все штрафы

## Проверка после применения

После применения миграции проверьте в Supabase Dashboard:

1. В разделе **Database** > **Tables** должна появиться таблица `fines`
2. В разделе **Database** > **Policies** должны быть созданы политики RLS
